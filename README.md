## 业务先行

客户建档 → 设备建档 → 合同占期审批 → 押金/租金登记 → 交付出库 → 退租计费 → 退款/补款 → 核销结清

合同确认时冻结日租金、押金与计费天数；按设备与日期区间检查重叠，交付还要校验设备状态、押金与客户赊欠上限。归还时计算超期费、损坏费和最终应收，余额不平不允许结清。

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 客户档案 | 客户联系资料与赊欠上限 | 新建、编辑、查询、详情、导出 |
| 租赁设备 | 唯一序列号设备、租金与维修状态 | 转入维修、维修完成 |
| 租赁合同 | 占期校验、收款、出库、退租与结清 | 确认档期、收款登记、交付出库、办理退租、押金退款、核销结清、撤销合同 |
| 资金流水 | 自动记录收款与退款，可追溯合同 | 业务动作自动生成、查询、追溯、导出 |
| 设备流转 | 交付与归还记录 | 业务动作自动生成、查询、追溯、导出 |

## 工程与验证

- 后端：Java 21 / Spring Boot 4.0.7 / JDBC / Flyway / MySQL 8.4，包名 `cn.zhuatech.rental`。
- 前端：Vue 3 / Vite / 原生 CSS，自适应桌面与移动端，业务端和管理端共用经鉴权的后端 API。
- 支持事务内多记录更新、乐观版本、幂等键、权限控制、提交审批分离、附件摘要、审计快照及 CSV 导出。

### 明确的功能边界

一期按单设备、自然日、固定日租金计费，支持多份合同，不含多币种、租金阶梯、保险计费、支付网关或自动开票。收退款是企业凭证核销记录，不会实际操作银行账户。

这是一套可运行、带业务测试的初版实现；测试通过不等于完成了所有生产环境的容量、安全、监管或现场验收。上线前需结合真实数据、业务制度和基础设施进行实施验证。
