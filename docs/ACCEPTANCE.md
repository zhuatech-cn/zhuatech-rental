# 主要功能验收矩阵

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 验收目标

客户建档 → 设备建档 → 合同占期审批 → 押金/租金登记 → 交付出库 → 退租计费 → 退款/补款 → 核销结清

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 客户档案 | 客户联系资料与赊欠上限 | 新建、编辑、查询、详情、导出 |
| 租赁设备 | 唯一序列号设备、租金与维修状态 | 转入维修、维修完成 |
| 租赁合同 | 占期校验、收款、出库、退租与结清 | 确认档期、收款登记、交付出库、办理退租、押金退款、核销结清、撤销合同 |
| 资金流水 | 自动记录收款与退款，可追溯合同 | 业务动作自动生成、查询、追溯、导出 |
| 设备流转 | 交付与归还记录 | 业务动作自动生成、查询、追溯、导出 |

## 界面验收

检查业务端模块列表、新建与详情、服务端错误反馈，以及管理端账号权限和审计入口；桌面截图及管理端截图见 README。所有演示金额和人员均为虚构。

## 不宣称已覆盖的事项

一期按单设备、自然日、固定日租金计费，支持多份合同，不含多币种、租金阶梯、保险计费、支付网关或自动开票。收退款是企业凭证核销记录，不会实际操作银行账户。

不将本机测试当成真实生产负载的压力测试，也不声称通过安全合规认证、故障切换或客户现场验收。测试事实见 [测试结果](TEST-RESULTS.md)。

## 增补安全与并发回归

四个不同请求同时修改同一版本，只允许一个成功；五次密码错误后暂时锁定；另一企业的 HTTP 会话无法读到单据、审计或附件；同一秒创建的记录使用数据库顺序号确定先后。
